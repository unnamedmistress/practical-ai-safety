# Contributing

Report a factual correction with the page URL, the specific claim, and a current primary source. Keep private chats, client details, access keys, and personal records out of issues and pull requests.

Use fictional examples. Keep public prose plain and specific. Do not add search-ranking promises, unsupported safety guarantees, tracking scripts, or new dependencies. Run `python check_site.py` before proposing changes.

This is an educational resource. There is no promised support response time.
